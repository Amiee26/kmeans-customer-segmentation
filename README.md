# Customer Segmentation using K-Means Clustering

## Objective
Segment customers into meaningful groups using clustering techniques.

## Tools Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Google Colab

## Dataset
Customer Personality Analysis Dataset (Kaggle)

## Techniques Used
- Data Cleaning
- Feature Engineering
- Standard Scaling
- Elbow Method
- Silhouette Score
- K-Means Clustering

## Results
Identified customer groups and generated business insights for targeted marketing.
